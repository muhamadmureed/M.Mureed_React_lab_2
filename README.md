# React Fundamentals - Lab 02

Student Name: Muhammad Mureed  
Project Name: M.Mureed_React_lab_2  
Tech Stack: React, Vite, Material UI (MUI)

## Project Overview

This project is built for Week 12 React Fundamentals (Lab 2). It implements a responsive homepage using Material UI (MUI) component library and structured with modular components.

## Components Structure

The application is decomposed into reusable functional components:
- `Navbar`: Responsive navigation bar with brand logo, links, and action button.
- `Hero`: Hero banner with headline, description, version badge, and call-to-action buttons.
- `Features`: Feature showcase using Material UI Grid, Cards, Avatars, and Icons.
- `Footer`: Bottom section with branding, quick links, social media icons, and copyright.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```
